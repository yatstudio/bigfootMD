# Bigfoot Note Trademark Policy

This policy covers the **Bigfoot Note** name, the Bigfoot Note logo, and related branding assets.

## Code license vs. trademarks

Bigfoot Note's source code is licensed under the GNU Affero General Public License v3.0 or later (AGPL-3.0-or-later).

That license applies to the code. It does **not** grant any right to use the Bigfoot Note name, logo, or branding.

## Allowed without asking

You may, without prior permission:
- refer to Bigfoot Note truthfully in commentary, documentation, blog posts, reviews, comparisons, or tutorials
- say that your project is based on, compatible with, or derived from Bigfoot Note, as long as that statement is accurate
- redistribute unmodified official releases while preserving existing notices
- make nominative use of the Bigfoot Note name to explain that you are discussing the original project

## Not allowed without prior written permission

You may not, without prior written permission:
- use the Bigfoot Note name or logo for a modified fork in a way that suggests it is the official project
- rebrand a hosted or commercial offering as "Bigfoot Note" if it is not the official Bigfoot Note service or product
- use the Bigfoot Note logo in product branding, app icons, domains, marketing pages, or store listings for a fork or derivative product
- imply endorsement, affiliation, sponsorship, or approval by the Bigfoot Note project, Luca Rossi, or Bigfoot Capital when none exists

## Forks and modified versions

If you fork or modify Bigfoot Note, you are welcome to do so under the AGPL, but you must choose your own name and branding for any redistributed or hosted version unless you have written permission to use the Bigfoot Note marks.

Good examples:
- "Fork of Bigfoot Note"
- "Based on Bigfoot Note"
- "Internal knowledge app derived from Bigfoot Note"

Bad examples:
- calling your modified product "Bigfoot Note"
- using the Bigfoot Note logo for your fork
- presenting your hosted fork as the official Bigfoot Note product

## Reservation of rights

All trademark rights in the Bigfoot Note name, logo, and branding are reserved.

Questions or permission requests should be directed to the project maintainer.
